# Generated bridge maps

This directory is a placeholder for runtime JSON/SVG maps produced by the bridge's legacy diagnostic mapper. Generated files are ignored by Git.

Authoritative ROS/Cartographer exports (`.pbstream`, `.pgm`, `.yaml`) are created under `/home/pi/gladis_maps` on BEEP. Keep only selected, inspected examples under `assets/ros_maps/`; do not confuse accumulating files with improving localization.
