# Offline observe-only supervisor checkpoint

**Status:** this particular harness remains a host-only **saved-fixture** replay: no bridge, ROS, ALSA, network, mixer, semantic motor dispatcher or live model is used by it. BEEP was off when this offline slice was accepted; later stationary powered readbacks are recorded separately in [Phase E stationary readback](PHASE_E_STATIONARY_READBACK.md). This harness does **not** authorize Phase E motion or itself claim live observation.

Run `python scripts/run_beep_autonomy.py --observe-only --output /path/to/report.json`. The required flag has no complementary motion mode. The script replays two saved **qualitative** camera/model packets through `PhaseARecorder` → `TacticalGate` → persistent `AgentSession` world → `StrategicModelSession` with an injected typed fake GLADIS proposal → `GoalCoordinator` → `CombinedCheckpoint`. A reconstructed supervisor loads the saved session/coordinator pair between windows. The report records journal count, model/coordinator decisions and checkpoint generations; it hard-labels the synthetic map/owner/clock context and `dispatch_performed=false`, `route_validated=false`, `physical_stop_verified=false`.

The replay's `ingest_approximate` acquisition time is synthetic boot-clock scaffolding; the saved packet's timestamps, guarded pose and motion lease **are not** promoted to exposure-time TF, map provenance, or physical movement. `PoseRing` cannot derive a metric camera pose from it and `PlaceGraph` stays empty. The cap mentioned in these historical fixtures is not an enduring goal. A future runner must receive independently proven sensor stamps and map revisions before spatial operations.

The host supervisor exposes **only** an observe method. It requires one exact stopped/unowned session, the same journal/session across components, matching map context and a bounded advisory tactical candidate. At construction and before every observation it checks the ordered journal acquisitions against world sequence/last packet and rereads the durable checkpoint; an unseen appended frame, failed checkpoint save, or mismatched generation fails closed even if the next frame has a different ID. It rejects non-increasing robot timestamps (including approximate stamps after restore) and preflights world updates on a copy **before** tactical state or journal writes. It then records acquisition, updates the qualitative world, runs one model window, takes an advisory coordinator decision and persists the pair. A restored strategic adapter fences windows at or below its restored world sequence. These checks do **not** make the journal and checkpoint one atomic transaction: reconciliation still requires explicit intervention. A real Pi producer, current-map reader, provider, local ownership readback and consent/privacy gates are still missing. Do not point this fake bridge replay at hardware merely by changing an address; there is deliberately no bridge address or actuator in the script.

Verify with `python -m unittest discover -s tests -p test_observe_only_supervisor.py -v` and the full test suite. These establish host control-flow contracts, not physical stop latency or autonomy.
